# OG 이미지 (1200×630)

결과 페이지의 `og:image` 는 `https://mindtest.chatgpts.kr/og/<slug>.png` 를 가리킨다.
카카오톡·인스타에 공유될 때 뜨는 카드가 이 사이트 마케팅의 전부이므로, 이 폴더를 채우는 게
배포 직후 가장 우선순위 높은 작업이다.

## 만들어야 할 파일 (총 31장)

| 파일 | 쓰이는 곳 |
|---|---|
| `default.png` | 홈 (index.html) |
| `love.png` `kkondae.png` `vocab.png` | 각 테스트 진행 페이지 |
| `love-<slug>.png` × 16 | 연애 스타일 결과 |
| `kkondae-<1..5>.png` × 5 | 꼰대력 결과 |
| `vocab-<8·7·6·5·4b·4>.png` × 6 | 어휘력 결과 |

정확한 파일명 목록은 아래 명령으로 뽑을 수 있다.

```
grep -rho 'og/[a-z0-9-]*\.png' . --include=*.html | sort -u
```

## 디자인 가이드

- 1200×630, 배경은 테스트 키 컬러(연애=코럴 `#ff7a7a`, 꼰대력=네이비 `#4a5b8c`, 어휘력=그린 `#3f9e73`)
- 가운데 큰 이모지 → 그 아래 결과명(굵게, 80px 이상) → 하단에 `마인드테스트`
- 카톡 미리보기는 정사각형으로 잘릴 수 있으니 **중요한 글자는 가운데 정사각 영역 안에** 배치
- 이미지가 없어도 페이지는 정상 동작한다 (미리보기 카드만 비어 보인다)

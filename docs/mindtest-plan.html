한자야 놀자!(hanja.chatgpts.kr)와 반대 성격(공유·바이럴)의 사이트로 포트폴리오 보완

1. 개요

항목내용
도메인mindtest.chatgpts.kr (chatgpts.kr 서브도메인 → 애드센스 심사 없이 즉시 게재)
사이트명마인드테스트

광고애드센스, tfat 없이 일반 대상 (한자 사이트와 달리 아동 태그 불필요)

2. 핵심 설계 원칙

1. 엔진과 데이터 분리 — 엔진 3종만 만들면, 이후 테스트 추가 = 데이터 파일 1개 (30분 작업)

2. 결과마다 고유 URL — result/love-tsundere.html 식. 공유된 링크가 곧 재유입 입구이자 검색 노출 단위

3. 결과별 OG 카드 — 카톡에 공유될 때 뜨는 이미지가 마케팅의 전부. 결과 페이지마다 og:image / og:title 개별 설정

4. 밈형 결과 네이밍이 승부처 — 기능보다 결과 이름("연락 집착러", "화석" 등)이 공유를 만든다

5. 테스트는 짧게 — 모바일 완주율 기준 10~12문항

3. 엔진 3종

엔진방식사용 테스트
engine-type.js축별 점수 누적 → 조합으로 유형 매칭 (예: 4축 → 16결과)연애 스타일
engine-score.js응답 점수 합산 → 구간별 등급 + %꼰대력
engine-quiz.js정답 채점 → 점수를 급수/레벨로 환산한자어 어휘력

공통 UI: 질문 1개씩 표시, 진행바, 뒤로가기, 결과 계산 후 결과 페이지로 이동.

공유: 링크 복사 + 카톡/X 공유 버튼 (URL 스킴만 사용, SDK 없이).

4. 런칭 3종

① 연애 스타일 테스트 — 16유형

  • 12문항, 4축 (표현/속도/거리감/현실감 같은 자체 축)
  • ⚠️ MBTI 명칭·공식 문항 사용 금지 (상표/저작권) — 구조만 16유형 차용, 문항 전부 자체 제작
  • 타겟: 불특정 바이럴 (인스타·카톡). 커플이 서로 시키는 재귀 공유 구조

② 꼰대력 테스트 — 점수 %

  • 10문항, 5등급 (예: 청정 MZ ~ 화석)
  • 결과 화면에 인증 문구 자동 생성: "나 꼰대력 73% ㅋㅋ"
  • 타겟: 블라인드·다모앙 등 직장인 커뮤니티 (댓글 인증 문화와 정합)

③ 한자어 어휘력 테스트 — 급수

  • 10문항 4지선다, playhanja grade-data.js 3,500자에서 출제 (남이 못 베끼는 데이터)
  • 결과: "당신의 어휘력은 준4급" + "이 급수 한자 공부하러 가기" → hanja.chatgpts.kr 크로스 퍼널
  • 타겟: 문해력 떡밥은 한국 커뮤니티 영구 소재 — 논란 터질 때마다 재점화

  • ☐ 엔진 + 연애 테스트 + 결과 16페이지
  • ☐ 전 페이지 canonical 태그
  • ☐ robots.txt / sitemap.xml
  • ☐ ads.txt + 애드센스 코드 (tfat 없음)
  • ☐ Vercel Analytics 활성화
  • ☐ 배포 직후 구글 서치콘솔 등록 (URL 접두어 + HTML 메타태그 방식) + 사이트맵 제출
  • ☐ 네이버 서치어드바이저 등록 (⚠️ 브라우저 확장이 네이버 콘솔 접근 불가 → 콘솔 조작은 직접, 메타태그 삽입·배포·확인은 Claude 분담)

9. 글로벌 확장 (2단계 로드맵)

심리테스트는 글로벌이 진짜 수익 구간이다. 선례: ktestone(컬러 성격 테스트)이

동남아·글로벌로 번져 한국 트래픽의 수십 배를 만든 사례.

  • 왜 개꿀인가: 미국·유럽 트래픽의 애드센스 단가는 한국의 수 배. 같은 테스트, 같은 서버비(0원)로 단가 높은 트래픽을 받는 구조
  • 정적 사이트라 번역이 쉬움: 언어별 데이터 파일 + /en/ 경로만 추가. 엔진·CSS는 공용. hreflang 태그로 언어별 검색 매칭
  • 글로벌 라인업은 다르다: - 잘 통함 — 연애 스타일, 성격 유형, 여행 스타일 (문화 중립) - 한국 전용 — 꼰대력(→ boomer test로 현지화 가능), 한자어 어휘력, 맞춤법
  • 번역이 아니라 현지화: 결과 이름의 밈은 직역하면 죽는다. 영어권 밈으로 다시 짓기 (예: "연락 집착러" → "Double-Texter")
  • 로케일 자동 감지: 접속자의 브라우저 언어(navigator.language)를 보고 맞는 언어 페이지를 안내. 단 강제 리다이렉트는 금지 — 크롤러가 원문에 못 들어와 SEO를 해친다. "English version available" 배너로 제안하는 방식이 정석. 언어별 URL(/en/love.html) + hreflang 상호 태그로 구글이 국가별로 알아서 매칭
  • 순서: 한국어로 먼저 검증 → 반응 온 테스트만 /en/ 추가. 전부 번역해두고 시작하지 말 것 (검증 전 비용)
